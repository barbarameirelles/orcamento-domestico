# Templates de mensagem para o grupo "APENAS GASTOS CASA"

Cole no grupo e **fixe** para não esquecer o padrão. O bot identifica quem pagou
pelo número de quem envia, então cada pessoa manda sem escrever o próprio nome.

Lembrete de divisão: `NN/NN` = `[quanto a Barbara arca]/[quanto o Felipe arca]`.
Ex: `100/0` = Barbara paga tudo · `0/100` = Felipe paga tudo · `50/50` = metade cada.

---

## 📋 Template da Barbara

```
📌 COMO LANÇAR MEUS GASTOS (Barbara)

Formato: valor descrição

Exemplos:
• 45,90 ifood
• 120 mercado
• R$ 89,90 farmácia

✅ Já entra no meu nome automaticamente
✅ A categoria é detectada sozinha
✅ Divisão 50/50 por padrão

Casos especiais:
• Gasto do Felipe: felipe 60 uber
• Outra divisão: 200 conserto 100/0
  (100/0 = eu pago tudo | 0/100 = Felipe paga tudo)

O robô responde ✅ quando cadastrar.
```
